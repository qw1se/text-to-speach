# Text to Speech

Небольшое браузерное приложение для озвучивания текста с помощью встроенного **Web Speech API**. Пользователь вводит текст, выбирает язык и доступный голос, настраивает скорость, тон и громкость, а затем запускает, приостанавливает, продолжает или останавливает воспроизведение.

https://text-to-speach-two.vercel.app/



## Возможности

- Озвучивание текста непосредственно в браузере без серверного API.
- Поддержка языков:
  - Русский (`ru-RU`)
  - English (US) (`en-US`)
  - English (UK) (`en-GB`)
  - Deutsch (`de-DE`)
  - Français (`fr-FR`)
  - Español (`es-ES`)
  - Italiano (`it-IT`)
  - 日本語 (`ja-JP`)
  - 中文 (`zh-CN`)
  - 한국어 (`ko-KR`)
- Выбор голоса из голосов, предоставленных текущим браузером и операционной системой.
- Настройка параметров речи:
  - скорость — от `0.5x` до `2.0x`;
  - тон — от `0` до `2`;
  - громкость — от `0%` до `100%`.
- Ограничение текста — `5000` символов.
- Управление воспроизведением: воспроизведение, пауза, продолжение и остановка.
- Индикатор состояния: готово, воспроизведение или пауза.
- Индикатор прогресса на основе событий границ слов и предложений Web Speech API.
- Адаптивный интерфейс на Tailwind CSS.
- Предупреждение, если браузер не поддерживает `speechSynthesis`.

## Технологии

- [React](https://react.dev/) 19
- [TypeScript](https://www.typescriptlang.org/) 5.9
- [Vite](https://vite.dev/) 7
- [Tailwind CSS](https://tailwindcss.com/) 4
- Web Speech API (`SpeechSynthesis`, `SpeechSynthesisUtterance`)
- `clsx` и `tailwind-merge` для объединения CSS-классов
- `vite-plugin-singlefile` для сборки приложения в один HTML-файл

## Требования

- Node.js и npm.
- Современный браузер с поддержкой Web Speech API. В интерфейсе приложения рекомендуются Chrome или Edge; также заявлена поддержка Safari.
- Доступные голоса зависят от браузера, операционной системы и установленных языковых пакетов.

## Установка и запуск

Клонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/qw1se/text-to-speach.git
cd text-to-speach
npm install
```

Запустите сервер разработки:

```bash
npm run dev
```

После запуска откройте адрес, который выведет Vite в терминале, обычно `http://localhost:5173`.

## Сборка и предпросмотр

Создайте production-сборку:

```bash
npm run build
```

Проверьте собранное приложение локально:

```bash
npm run preview
```

Результат сборки помещается в каталог `dist/`. Конфигурация Vite подключает React, Tailwind CSS и `vite-plugin-singlefile`, поэтому production-сборка также подготавливается для упаковки приложения в один HTML-файл.

## Использование

1. Откройте приложение в поддерживаемом браузере.
2. Введите или вставьте текст в поле. Текст автоматически ограничивается 5000 символами.
3. Выберите язык.
4. При необходимости выберите конкретный голос из списка доступных голосов.
5. Настройте скорость, тон и громкость.
6. Нажмите **«Воспроизвести»**.
7. Во время воспроизведения используйте **«Пауза»** или **«Стоп»**. После паузы доступна кнопка **«Продолжить»**.

Приложение не отправляет текст на сервер: озвучивание выполняется локально через API браузера. Это также означает, что итоговое качество и набор голосов зависят от используемого браузера и операционной системы.

## Как устроена логика

`src/main.tsx` монтирует компонент `App` в элемент `#root` и подключает глобальные стили. В `src/App.tsx` хранятся состояние текста, выбранного языка и голоса, параметры речи, текущий статус и прогресс.

При запуске компонент получает голоса через `window.speechSynthesis.getVoices()` и обновляет их после события `voiceschanged`. При нажатии кнопки воспроизведения создаётся `SpeechSynthesisUtterance`, которому передаются текст, язык, голос, скорость, тон и громкость. События `onstart`, `onboundary`, `onend` и `onerror` синхронизируют состояние интерфейса и прогресс.

При размонтировании компонента активная речь отменяется, а таймер обновления прогресса очищается. Утилита `cn` предусмотрена для объединения классов Tailwind, хотя основной компонент использует классы непосредственно в JSX.

## Ограничения

- Если браузер не поддерживает Web Speech API, озвучивание недоступно.
- Список голосов загружается браузером и может быть пустым или отличаться на разных устройствах.
- Прогресс является приблизительным: он вычисляется по `charIndex` из событий `onboundary`, а не по точному времени аудио.
- Текст и настройки не сохраняются между перезагрузками страницы.
- Экспорт результата в аудиофайл и серверная генерация аудио не реализованы.
